# Karobar POS releases

This repository holds only the installers and update packages for Karobar POS. It has no source code.

- **Install:** download `KarobarPOS-stable-Setup.exe` from the [latest release](../../releases/latest).
- **Updates:** installed copies check this repository by themselves and update in the background. Nothing needs to be done here.
- **Beta:** releases marked *Pre-release* are the beta channel.
